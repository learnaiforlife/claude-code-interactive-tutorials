# Product

## Register

product

## Users

Developers new to Claude Code (first-time setup, learning core workflows)
and intermediate users (building habits, discovering advanced patterns).
Context: typically at a terminal or in an IDE, learning on their own time.
Job to be done: understand how Claude Code works and build real fluency, fast.

## Product Purpose

A free, interactive tutorial platform for Claude Code. Users learn by doing —
not by reading docs. Success means a user completes a lesson and immediately
applies it in their own workflow. No sign-up gate, no paywall, no fluff.

## Brand Personality

Precise, approachable, playful, opinionated, focused.
Tone: a sharp senior developer who enjoys teaching — direct without being cold,
confident without being arrogant, occasionally witty without being distracting.

## Anti-references

- Predictable purple gradients (generic AI SaaS visual)
- Generic SaaS card grids (icon + heading + text, repeated)
- Glassmorphism as decoration
- Empty marketing-site visuals (hero illustrations that say nothing)
- GitBook / Notion-style plain docs UI (too passive, no visual opinion)
- claudecodeguide.dev — calm but static, no interactivity, no distinct visual identity

## Design Principles

1. **Teach by doing** — the interface is a learning environment, not a doc reader.
   Every screen invites action.
2. **Code is first-class** — typography and layout make code beautiful and readable,
   not an afterthought wedged into a prose layout.
3. **Opinionated, not arbitrary** — strong visual choices that feel intentional.
   The UI has a point of view.
4. **Progressive depth** — beginners and intermediates share the same surface;
   depth is unlocked by engagement, not hidden behind tabs.
5. **Earn every element** — nothing decorative that doesn't teach or orient.
   Motion, color, and copy all carry meaning.

## Accessibility & Inclusion

WCAG AA. Reduced-motion support required on all animations.
Code blocks must meet contrast requirements, not just body text.
